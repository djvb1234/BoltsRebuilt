# v0.1.0-preview.1 — source developer preview

This is the first tagged BoltsRebuilt preview: a fixed source version for people
who want to build locally and report results. It is an early testing release,
not a claim of complete-game compatibility.

**There is no prebuilt game executable.** GitHub's Source code downloads contain
the repository's source and documentation. You need your own supported PAL game
extraction and the Windows development tools to build and run it. Game files,
generated game C++, captured/translated game shaders, binaries, saves and private
asset caches are not included.

## Included

- Windows host application on the pinned RexGlue v0.10.0 SDK, with seven local patches.
- Custom D3D12 renderer, local shader translation/preparation, and per-draw fallback.
- Ultrawide view and HUD support, with 21:9/32:9 options and configurable render scale.
- Local build/play helpers, issue forms, a first-playtest guide and troubleshooting.
- Six documented development screenshots, an architecture guide, hardware details
  and a compatibility record.
- Publication/Python checks and game-free Windows helper/ultrawide checks in CI.

## Start here

```powershell
git clone --branch v0.1.0-preview.1 --depth 1 https://github.com/djvb1234/BoltsRebuilt.git
cd BoltsRebuilt
```

Then follow the
[build guide for this version](https://github.com/djvb1234/BoltsRebuilt/blob/v0.1.0-preview.1/docs/BUILDING.md)
and [first-playtest steps](https://github.com/djvb1234/BoltsRebuilt/blob/v0.1.0-preview.1/docs/FIRST_PLAYTEST.md).
The tag checkout is a fixed snapshot; include `v0.1.0-preview.1` and your commit
when reporting results.

The target is Windows x64, an x86-64-v2 CPU and Direct3D 12. The tools require
PowerShell 7, Python 3.11+, Git, Visual Studio 2022 C++/Clang tools and a Windows SDK.
The accepted PAL executable SHA-1 is
`5be7c41a37e3fa1e8fa05f4a0815c9b807dcae74`. Title updates and other executable
versions are outside the supported inputs.

## What has been checked

The public runtime built from a fresh pinned SDK and reached the title screen
in capture mode and native-enabled mode on the maintainer's machine. The native
launch used only three vertex and three pixel shader stages, with fallback for
other draws. The later documentation and CI additions do not extend those
gameplay claims. The Python suite has 55 tests; these are source/tool checks.

The test machine is an Intel Core Ultra 9 285K with an NVIDIA GeForce RTX 5070 Ti,
32 GB RAM, Windows 11 IoT Enterprise LTSC build 26100, NVIDIA driver 616.56 and an
MSI MPG 491C OLED at 5120 x 1440 / 144 Hz. These are observed specifications,
not minimum requirements or a measured game frame rate.

See the [validation record](https://github.com/djvb1234/BoltsRebuilt/blob/v0.1.0-preview.1/docs/VALIDATION.md)
and [hardware details](https://github.com/djvb1234/BoltsRebuilt/blob/v0.1.0-preview.1/docs/TEST_HARDWARE.md).

## Known limits

- Full-game progression, extended save/reload, other GPU vendors/models and other
  driver combinations are not established by the published checks.
- Native coverage depends on your local shader library and supported draw state.
  Unsupported work retains fallback; native replacements require the SDK's
  bindless path and Resource Binding Tier 2 or higher.
- The high guest refresh default permits up to 240 FPS and can speed up
  frame-counted behavior. The build guide explains the original 30 FPS setting.
- Private development screenshots and performance observations are not benchmarks
  or compatibility results for this source preview.

[Compatibility details](https://github.com/djvb1234/BoltsRebuilt/blob/v0.1.0-preview.1/docs/COMPATIBILITY.md)
