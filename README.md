# Renut Research

Research and experiments exploring Banjo-Kazooie: Nuts & Bolts, with a focus on rendering, ultrawide display support, and performance.

This repository is being prepared for its first public research release. The initial commit establishes the repository; findings, tools, benchmark details, and ultrawide screenshots will be added as they are reviewed and organized.

The project is experimental. Results should be read alongside their game version, emulator or runtime version, configuration, and reproduction steps when published.

Game images, game executables, extracted assets, and local research archives are not included.
